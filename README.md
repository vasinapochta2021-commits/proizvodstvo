# Производство — часть 1

Вход, команда и права, станки, каталог деталей (сетапы, программы, время), изделия, калькулятор материала.
«В работе» и «Готовые» пока заглушки — будут в следующей части.

## 1. Новый проект Firebase
1. https://console.firebase.google.com → **Добавить проект** (имя любое, Google Analytics выключить).
2. Тариф **Spark** (бесплатный) — карта не нужна.

## 2. Включить вход и базу
- **Build → Authentication → Начать → Email/Password → включить**.
- **Build → Firestore Database → Создать базу** (режим «рабочий», регион `eur3` или ближайший).

## 3. Конфиг
**Настройки проекта (шестерёнка) → Ваши приложения → Web (`</>`)** → зарегистрировать → скопировать значения `apiKey, authDomain, projectId, appId` в файл `config.js`.

## 4. Правила доступа
**Firestore → Правила** → вставить всё из `firestore.rules` → **Опубликовать**.

## 5. Первый администратор (один раз, руками)
1. **Authentication → Users → Добавить пользователя**: email `ваш_логин@prod.local` (например `admin@prod.local`), пароль от 6 символов. Скопируйте его **UID**.
2. **Firestore → Начать коллекцию** `users` → ID документа = этот UID, поля:
   - `name` (string) — ваше имя
   - `login` (string) — `admin`
   - `active` (boolean) — `true`
   - `isAdmin` (boolean) — `true`
   - `perms` (map) — пустая
3. Дальше всех остальных (Олег, Антон, слесари) создаёте уже в приложении: вкладка **Команда**.

## 6. Выложить на GitHub Pages
Новый репозиторий → загрузить все файлы из папки (кроме `backend-mem.js` и этого README, они не нужны) → **Settings → Pages → Deploy from branch → main / root**.

## Заметки
- Логин в приложении — латиница; внутри это `логин@prod.local`.
- Пароль забыли: отключите человека и создайте заново под новым логином.
- Чертежи (PDF/фото до 8 МБ) лежат в Firestore. STEP и Telegram — позже, после выбора бесплатного варианта без карты.
- Права проверяются правилами Firestore, а не только скрыты в интерфейсе.
